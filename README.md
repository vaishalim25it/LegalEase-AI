# LegalEase-AI

AI-Powered Legal Document Generator using Python, FastAPI, Streamlit and Google Gemini AI.

## Features

- Generate legal document drafts
- Employment contracts
- Lease agreements
- AI-powered content generation
- Edit and preview documents
- Download as TXT, DOCX and PDF

## Technologies Used

- Python
- FastAPI
- Streamlit
- Google Gemini AI
- python-docx
- fpdf2
